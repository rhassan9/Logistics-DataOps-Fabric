# Fabric item definitions

This folder is managed by Microsoft Fabric Git integration. Its contents are item
definitions (notebooks, lakehouses, Copy jobs, Variable Libraries) serialised by Fabric
and synchronised with the workspace.

Do not edit these files by hand. Make changes in the Fabric workspace and commit from the
Source control pane. Manual edits can break the sync and produce conflicts that are
awkward to resolve.

Project documentation is in the [repository root README](../README.md).
